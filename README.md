# Physica ($PHYSICA)

AI-powered physics discovery and autonomous research laboratory.
Simulate reality. Discover the unknown.

## Files
- `index.html` — the full site (Universe lab, Experiments, Theory notebook, $PHYSICA)
- `logo.png` — logo and favicon
- `middleware.js` — Vercel middleware that powers the theory notebook at `/api/theory`
- `vercel.json` — Vercel config

## Deploy on Vercel
1. Push these files to the root of a GitHub repo and import it in Vercel (Framework preset: **Other**, no build command).
2. In Vercel → Project → Settings → Environment Variables, add `ANTHROPIC_API_KEY`.
3. Redeploy.
